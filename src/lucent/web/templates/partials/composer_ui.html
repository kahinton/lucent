{# Shared Agent Composer UI primitives. The definitions page had drifted from the rest of the app in three ways that actually mattered: 1. Each tab opened with an intro callout in a *different* accent colour (teal, amber, orange, emerald, primary) and, worse, used `text-{colour}-900` on a `bg-{colour}-50` panel. The app forces dark mode, so `bg-*-50` is repainted to a translucent tint while `text-*-900` is left as a near-black literal — measured contrast was 1.34:1 to 2.21:1 against a 4.5:1 floor. The headings were effectively invisible. 2. Actions were tinted fills (`bg-purple-50 text-purple-700`, `bg-primary-50 text-primary-700`) instead of the app's single primary button, so no two tabs looked like they belonged to the same product. 3. There were four different type scales for the same object (card titles, metadata rows, section headings).
