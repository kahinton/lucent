The function receives one dict argument and must return JSON-serializable data. It runs inside a sandbox container, not on the host.

Use {argument} for model-supplied values and {{ '{{env:NAME}}' }} for a credential defined below. The URL must not contain a username or password.

The document is stored with the tool, so an approved tool always calls the same fixed operation instead of whatever the server serves later. Remote $ref targets are not allowed.

A built-in action's argument schema comes from Lucent, not from this form, so an approved tool cannot be widened later.
