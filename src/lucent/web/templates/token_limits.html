How limits combine

Several policies can apply

A request is checked against every policy that reaches the person and the model. The tightest remaining budget wins, so you can give one group a larger allowance than everyone else.

Shared vs per person

A shared pool is one budget for everyone the policy covers. A per-person pool gives each covered person that full amount independently.

Rolling windows

Windows look backwards from right now rather than resetting at midnight, so usage can't be doubled by bursting across a boundary.

The daemon runs as a separate process and re-reads policies every {{ cache_ttl_seconds }} second{{ '' if cache_ttl_seconds == 1 else 's' }}; changes made here take effect within that window.
